Vérifier mon installation

Teste l'interface DMX, liste les boîtiers USB branchés et cherche les boîtiers réseau. À savoir : le DMX ne circule que dans un sens, les lampes ne répondent jamais — aucun logiciel ne peut donc « détecter » un BEAM 100. Pour vérifier qu'une lampe est bien à son adresse, utilise allumer sur la lampe, plus bas.

Comment ça marche

  1. Branche l'interface DMX, puis Réglages → assistant de démarrage.
  2. Sur la page Live, clique un look : tout le rig change d'un coup.
  3. Tape 4 fois sur TAP au rythme du kick, les effets se calent dessus.
  4. Pas envie de t'en occuper ? Choisis Chill, Normal ou Ça envoie : le logiciel enchaîne les looks tout seul.
  5. 🎯 Viser : glisse ton doigt sur l'aperçu, les lampes suivent.
  6. ✏️ Tracé : pose des points sur l'aperçu, les têtes tournent en boucle sur la courbe qui les relie — glisse un point pour la déformer.
  7. Couleurs : chaque point est une couleur de la roue de tes lampes. Clique pour l'ajouter à la palette, reclique le point pour l'enlever.
